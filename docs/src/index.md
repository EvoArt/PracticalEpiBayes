# PracticalEpiBayes.jl

Glue between [EpidemicTrajectories.jl](https://github.com/EvoArt/EpidemicTrajectories)
(epidemic likelihoods and iFFBS latent samplers) and
[PracticalBayes.jl](https://github.com/EvoArt/PracticalBayes.jl): Gibbs kernels that
plug an EpidemicTrajectories model into a PracticalBayes `@model`.

See the [API](api.md) for every exported function.
